# Локальные патчи скиллов

Здесь лежат инструкции по повторному наложению правок на скиллы из `~/.claude/skills/`,
которые **устанавливаются из внешнего источника** и потому затираются при обновлении.

Один файл = один пропатченный скилл, имя файла = имя скилла.

Формат каждого файла: что делает апстрим, что и почему меняем, точные правки, как проверить.
Файлы живут **вне** директории скилла — иначе переустановка снесла бы и сам патч.

## Как этим пользоваться

После обновления/переустановки скилла из первоисточника:

> Перечитай `~/.claude/local-patches/<имя-скилла>.md` и наложи описанный там патч заново
> на `~/.claude/skills/<имя-скилла>/`.

Если апстрим изменился настолько, что патч не ложится дословно — примени его по смыслу
и обнови сам файл патча под новый апстрим.

## Текущие патчи

- [improve-codebase-architecture.md](improve-codebase-architecture.md) — два патча: отчёт публикуется артефактом, а не HTML-файлом в `/tmp` с CDN; вопросы задаются через `AskUserQuestion`, а не текстом `❓ Q1 / ➡️`.
- [code-review.md](code-review.md) — описание PR читается как часть спеки (зафиксированные там расхождения с issue — решения, а не находки); вместо summary всех находок скилл идёт циклом по каждой issue: детальная карточка (код в fenced-блоках, прозаический разбор), план фикса через `fable-planner` на каждую issue, резолюция оператора, отбитый баннером переход; плюс два аргумента скилла (модель планировщика, режим принятия решений `manual|auto`), закрытие ветки коммитом, пушем и `/pr_description`, и запуск саб-агентов одним блоком в одном сообщении с вынесенным в отдельный файл `smells.md` baseline'ом запахов.
