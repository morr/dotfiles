# CLAUDE.md

Рабочая настройка обхода DPI на этом Mac.
**Полный рунбук — в `README.md` рядом. Прочитай его прежде, чем что-то менять или диагностировать.**

## Развёртывание на новой машине

`./setup.sh` — идемпотентный установщик: ставит зависимости, собирает tpws и ciadpi,
проводит через GUI-шаги (Install Service, флаги Chrome) с проверкой результата,
настраивает стратегию, блокировку QUIC и шифрованный DNS. `--rebuild` заставляет
пересобрать приложение, `--help` — короткая справка. Пишет полный лог в `~/dpi-bypass-setup-*.log`.

Повторный запуск на настроенной машине проходит целиком на «ПРОПУСК»: сборка,
перезапуск сервиса и перезапуск DNS-демона выполняются только если что-то реально изменилось.

## Быстрая шпаргалка

- Сервис: `sudo /opt/darkware-zapret/init.d/macos/zapret restart` — работает **без пароля**
  (правило в `/etc/sudoers.d/darkware-zapret`), так что перезапускать можно самому.
- Стратегия: `/opt/darkware-zapret/config_custom`, права 666 — правится **без sudo**.
  Рабочая для 443: `--split-pos=midsld --disorder`.
- DNS: `dnscrypt-proxy` на `127.0.0.1:53`. Системный резолвер провайдер подменяет,
  публичные DNS по UDP тоже.
- Всё остальное в `/opt` принадлежит root — писать туда только через команду для пользователя.

## Правила работы с этим стендом

1. **Не долбить заблокированный хост запросами.** После ~15 подряд провайдер начинает резать
   адрес наглухо на час-другой, и любые сравнения стратегий превращаются в мусор.
   Между замерами — пауза, контроль на незаблокированном хосте.
2. **curl и Chrome ломаются по-разному** — у них разный ClientHello (325 байт против ~1800).
   Стратегию проверять обоими: `curl` и headless Chrome со свежим профилем
   (`--headless=new --user-data-dir=$(mktemp -d) --dump-dom`).
3. **Успех Chrome мерить размером DOM, а не заголовком** — на странице ошибки Chrome ставит
   заголовком имя хоста.
4. **Отладка tpws**: `--debug=@/tmp/tpws.log` первой строкой в `TPWS_OPT`. В лог попадают имена
   посещённых сайтов — после диагностики убрать опцию и удалить файл.
5. Копии профиля Chrome для экспериментов содержат куки — удалять сразу после.

## Что уже проверено и НЕ работает

Порт 80 (перехват по IP), движок ciadpi/ByeDPI (`-d`/`-q` рвут любое соединение на macOS),
ECH (Cloudflare не публикует ключи), профиль macOS с DoH (не создаётся VPN-сервис).
Подробности и доказательства — в `README.md`, раздел «Тупики».

Замедление входящего потока (rutracker, x.com, discord — ~20 КБ и тишина) на macOS
не лечится: нужен пакетный движок (`nfqws`/`winws`), которого здесь нет.
